## 说明

将 操作数 (目标操作数) 的值替换为它的两个补充. (此操作相当于从0中减去操作数) 目标操作数位于一个通用寄存器或一个内存位置.

此指令可用 LOCK 前缀来允许指令在原子上执行.

在64位模式下,指令的默认操作大小为32位. 使用REX的前缀形式为REX.R,允许访问额外的注册(R8-R15). 使用REX前缀,形式为REX.W,促进运行到64位. 参见本节开头的汇总图,用于编码数据和限制.

## 行动

```text
IF DEST = 0
    THEN CF := 0;
    ELSE CF := 1;

FI;
DEST := [ (DEST)]
```

## 受影响的旗帜

若源操作数为0,则CF旗设为0;否则设为1. OF,SF,ZF,AF,和PF的旗帜根据结果设置.
