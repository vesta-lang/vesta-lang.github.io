summary: 对下四张 SHA256 信件进行中间计算
---

## 说明

SHA256MSG1指令是两个SHA256消息调度指令之一. 该指令对接下来的4个 SHA256 消息词进行中间计算.

## 行动

```text
SHA256MSG1
W4 := SRC2[31: 0] ;
W3 := SRC1[127:96] ;
W2 := SRC1[95:64] ;
W1 := SRC1[63: 32] ;
W0 := SRC1[31: 0] ;

DEST[127:96] := W3 + 0( W4);
DEST[95:64] := W2 + 0( W3);
DEST[63:32] := W1 + 0( W2);
DEST[31:0] := W0 + 0( W1);
```

## Intel C/C++ 内在编译器

```c
SHA256MSG1 __m128i _mm_sha256msg1_epu32(__m128i, __m128i);
```
