## 说明

交换目的地(第一)和源(第二)操作数的内容。 操作数可以是两个通用登记册或一个登记册和一个内存位置. 如果引用一个内存操作数,处理器的锁定协议在交换操作期间自动执行,无论LOCK前缀是否存在,或IOPL的值. (关于锁定协议的更多信息,见本章中的LOCK前缀描述. )

本指令对于实施过程同步的semaphores或类似的数据结构很有用. (见英特尔(R)64和IA-32架构软件开发者手册第3A卷第9章中的"巴士锁定",关于巴士锁定的更多信息).

XCHG指令也可以用来代替16位操作数的BSWAP指令.

在64位模式下,指令的默认操作大小为32位. 使用REX的前缀形式为REX.R,允许访问额外的注册(R8-R15). 使用REX前缀,形式为REX.W,促进运行到64位. 参见本节开头的汇总图,用于编码数据和限制.

NOTE

XCHG(E)AX,(E)AX(编码指令字节为90H)是NOP的别名,不分数据大小前缀,包括REX.W.

## 行动

```text
TEMP := DEST;
DEST := SRC;
SRC := TEMP;
```

## 受影响的旗帜

None.
