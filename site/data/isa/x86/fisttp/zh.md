summary: 以截流存储整数
---

## 说明

FISTTP将ST中的值转换成一个签名的整数,使用切换(chop)作为圆形模式,将结果传输到目的地,以及流行ST. FISTTP接受单词,短整数,长整数目的地.

下表显示以整数格式存储各类数字时获得的结果.

** FISTTP 结果**

| - | or | DEST 格式的值太大 | * |
| --- | --- | --- | --- |
| F | -1 |  | -I |
| -1<F< | +1 |  | 0 |
| FS+ 1 |  |  | +I |

## 行动

```text
DEST := ST;
pop ST;
```

## 受影响的旗帜

C1 is cleared; C0, C2, C3 undefined.

## 数字例外

无效, 堆叠无效( 上下流), 精度 。
