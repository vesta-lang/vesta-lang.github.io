---
summary: 对照边界检查阵列索引
---

## 说明

BOUND确定第一个操作数(阵列指数)是否在指定的一个阵列的边界内,第二个操作数(范围操作数). 数组索引是位于寄存器中的签名整数。 边框操作数是一个内存位置,它包含一对签名的双字插入符(当操作数的大小属性为32)或一对签名的单字插入符(当操作数的大小属性为16). 第一双词(或单词)是数组的下限,第二双词(或单词)是数组的上限. 数组指数必须大于或等于下限,小于或等于上限加上字节中的操作数大小. 如果索引不在界限内,则表示一个BOUND范围超过例外(#BR). 当生成此例外时,保存的返回 指令指针 指向 BOUND 指令.

边框限制数据结构(包含数组下限和上限的两字或双字)通常放在数组本身之前,使得极限可以通过从数组开始的常数抵消来进行处理. 由于数组的地址已经存在于寄存器中,这种做法避免了额外的总线周期,以获得数组界限的有效地址.

此指令以兼容模式和遗留模式执行 。 在64位模式下无效 。

## 行动

```text
IF 64bit Mode
    THEN
          #UD;
    ELSE
          IF (ArrayIndex < LowerBound OR ArrayIndex > UpperBound) THEN
          (* Below lower bound or above upper bound *)
                IF <equation for PL enabled> THEN BNDSTATUS := 0
                #BR;
          FI;

FI;
```

## 受影响的旗帜

None.
