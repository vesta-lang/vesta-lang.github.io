## 说明

SHA256MSG2指令是两个SHA2消息调度指令之一. 该指令对下四个 SHA256 信件词进行最终计算。

## 行动

```text
SHA256MSG2
W14 := SRC2[95:64] ;
W15 := SRC2[127:96] ;
W16 := SRC1[31: 0] + 1( W14) ;
W17 := SRC1[63: 32] + 1( W15) ;
W18 := SRC1[95: 64] + 1( W16) ;
W19 := SRC1[127: 96] + 1( W17) ;

DEST[127:96] := W19 ;
DEST[95:64] := W18 ;
DEST[63:32] := W17 ;
DEST[31:0] := W16;
```

## Intel C/C++ 内在编译器

```c
SHA256MSG2 __m128i _mm_sha256msg2_epu32(__m128i, __m128i);
```
