## 说明

从第二批操作数(源操作数)指定的区段描述符(见下文)中将区段限制装入第一批操作数(目标操作数),并在EFLAGS登记册中设置ZF旗. 源操作数(可以是寄存器,也可以是内存位置)包含用于访问的片段描述符的段选择子. 如果源操作数是一个内存地址,则只能访问16位数据. 目标操作数是一个通用寄存器.

作为加载过程的一部分,处理器执行访问检查. 一旦加载到目的地寄存器中,软件可以比较段限与一个指针的抵消.

线段限制是一个包含在字节0和1以及线段描述符前4位6中的20位值. 如果描述符有字节颗粒区段限制(颗粒性旗设定为0),则目标操作数按从描述符读取的字节颗粒值(字节限制)加载. 如果描述符有页面颗粒区段限制(颗粒性旗设定为1),则LSL指令会在加载到目标操作数之前将页面颗粒限制(页数限制)翻译为字节限制. 翻译是通过转移20位"raw"限制左移12位并用1s填充低序12位来完成的.

当操作数大小为16位时,会计算出一个有效的32位字节限制;然而,上16位被截断,只有低序的16位被装入目标操作数;目的地的上位未被修改. 当操作数大小是32位时,32位字节限制被装入目标操作数;目的地的上位被清除. 当操作数为64位时,32位字节限制为零延伸至64位并装入目标操作数. (32位和64位操作数大小的行为是相同的.

## 行动

```text
IF SRC(Offset) > descriptor table limit
    THEN ZF := 0; FI;

Read segment descriptor;

IF SegmentDescriptor(Type)  conforming code segment

and (CPL > DPL) OR (RPL > DPL)
or Segment type is not valid for instruction

          THEN
                ZF := 0;

          ELSE
                temp := SegmentLimit([SRC]);
                IF (SegmentDescriptor(G) = 1)
                      THEN temp := (temp << 12) OR 00000FFFH;

             ELSE IF OperandSize = 32

                      THEN DEST := temp; FI;

             ELSE IF OperandSize = 64 (* REX.W used *)

                      THEN DEST := temp(* Zero-extended *); FI;

             ELSE (* OperandSize = 16 *)

                      DEST := temp AND FFFFH;
                FI;
FI;
```

## 受影响的旗帜

ZF旗如果成功加载段限,则设为1;否则,设为0. CF, OF, SF, AF,和PF 旗帜不修改.
