## 说明

添加 目标操作数(第一个操作数)和 源操作数(第二个操作数),然后将结果存储到 目标操作数. 目标操作数可以是寄存器或内存位置;源操作数可以是即时寄存器,也可以是内存位置. (然而,两个内存操作数不能在一个指令中使用. )当一个即时值作为操作数时,其符号扩展为目标操作数格式的长度.

ADD 指令执行整数加法 。 它评价签名和未签名的整数操作数的结果,并设置OF和CF旗,分别表示签名或未签名结果中的结转(溢出). SF旗表示签名结果的标志.

此指令可用 LOCK 前缀来允许指令在原子上执行.

在64位模式下,指令的默认操作大小为32位. 使用REX的前缀形式为REX.R,允许访问额外的注册(R8-R15). 使用REX前缀,形式为REX.W,促进运行到64位. 参见本节开头的汇总图,用于编码数据和限制.

## 行动

```text
DEST := DEST + SRC;
```

## 受影响的旗帜

OF,SF,ZF,AF,CF,和PF的旗帜根据结果设置.
