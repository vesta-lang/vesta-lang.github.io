## 说明

复制源操作的字(第二个操作),并在与顺序操作(第三个操作)选择的字位位置插入目的地操作(第一个操作). 这一操作与PSHUFD指令使用的操作类似,图4-16对此进行了说明. 对于 PSHUFW 指令,顺序中的每个2位字段会选择目的地操作中一个单词位置的内容. 命令 操作数字段的编码从 源操作数 中选择要复制到 目标操作数 的单词.

源操作数可以是MMX技术寄存器或64位内存位置. 目标操作数是一个MMX技术登记册. 操作数的命令是8位即时命令. 请注意,本指令允许将 源操作数 中的单词复制到 目标操作数 中的多个单词位置.

在64位模式中,使用REX前缀的形式为REX.R,允许此指令访问额外的注册(XMM8-XMM15).

## 行动

```text
DEST[15:0] := (SRC >> (ORDER[1:0] * 16))[15:0];
DEST[31:16] := (SRC >> (ORDER[3:2] * 16))[15:0];
DEST[47:32] := (SRC >> (ORDER[5:4] * 16))[15:0];
DEST[63:48] := (SRC >> (ORDER[7:6] * 16))[15:0];
```

