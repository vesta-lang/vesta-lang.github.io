summary: 调整 RPL 段选择子 字段

## 说明

比较两个段选择器的 RPL 字段。 第一个操作数(目标操作数)包含一个段选择子,第二个操作数(源操作数)包含另一个. (RPL球场位于每个操作数的0位和1位. ) 如果目标操作数的RPL球场小于源操作数的RPL球场,则设置ZF旗,增加目标操作数的RPL球场,以配合源操作数. 否则,ZF旗被清除,目标操作数没有更改. (目标操作数可以是单词寄存器或内存位置;源操作数必须是单词寄存器.

ARPL指令由操作系统程序提供使用(然而,它也可以被应用程序使用). 一般用于调整一个段选择子的RPL,该段选择子通过一个应用程序传递到操作系统中,以匹配应用程序的特权级别. 在这里,传递到操作系统的段选择子被放置在目标操作数和段选择子中,用于应用程序的代码段被放置在源操作数中. (源操作数中的RPL字段代表应用程序的特权级别. )执行ARPL指令后,确保操作系统收到的段选择子的RPL不会比应用程序的特权级别(程序调用后,应用程序代码段的段选择子可以从堆栈读取)更低(没有更高的特权).

此指令以兼容模式和遗留模式执行 。 它不能以64位模式编码 。

参见Intel(R)64和IA-32架构软件开发者手册第3A卷第3章"保护-模式内存管理"中的"检查呼叫者访问权限",以了解关于本指令使用的更多信息.

## 行动

```text
IF 64-BIT MODE

    THEN
          See MOVSXD;

    ELSE
          IF DEST[RPL] < SRC[RPL]
                THEN
                      ZF := 1;
                      DEST[RPL] := SRC[RPL];
                ELSE
                      ZF := 0;
          FI;

FI;
```

## 受影响的旗帜

若目标操作数的RPL场小于源操作数场,则ZF旗设为1;否则则设为0.
