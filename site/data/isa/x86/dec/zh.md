## 说明

从 目标操作数 中减去 1,同时保留 CF 旗的状态. 目标操作数可以是寄存器或内存位置. 此指令允许在不干扰CF旗的情况下更新循环计数器. (为了执行更新CF旗的减速操作,使用SUB指令,其中立即数操作数为1).

此指令可用 LOCK 前缀来允许指令在原子上执行.

在64位模式中,DEC r16和DEC r32不能编码(因为操作码 48H通过4FH是REX的前缀). 否则,该指令的64位模式默认操作大小为32位. 使用REX.R前缀可以访问额外的登记册(R8-R15). 使用REX.W前缀将操作提升到64位.

参见本节开头的汇总图,用于编码数据和限制.

## 行动

```text
DEST := DEST  1;
```

## 受影响的旗帜

CF旗不受影响. OF,SF,ZF,AF,和PF的旗帜根据结果设置.
