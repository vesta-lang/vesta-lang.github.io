---
summary: 如果条件已满足则跳转
---

## 说明

检查EFLAGS登记册(CF,OF,PF,SF,和ZF)中一个或多个状态标志的状态,如果旗帜处于指定的状态(条件),则跳转到目标操作数指定的目标指令. 每个指令都附有一个条件代码(cc),以说明所测试的条件。 如果条件不能满足,则跳跃不进行,执行继续遵循Jcc指令的指示.

目标指令以相对偏移(与EIP登记册中的指令指针的当前值相对的签名偏移)来指定. 相对偏移(rel8,rel16,或rel32)在组装代码中一般被指定为标签,但在机器代码级别上,它被编码为签名,8位或32位的即时值,该值被添加到指令指针中. 指令编码对128至+127的抵消效率最高. 如果 操作数 大小属性为 16,则EIP 寄存器的上两个字节被清除,导致 指令指针 最大大小为 16 比特.

每个Jcc元音的条件在上页表格的"描述"栏中给出. 比较有符号整数时使用"小"和"大"两个词,比较无符号整数时使用"以上"和"以下"两个词.

由于状态标志的特定状态有时可以有两种解释,因此对一些操作码定义了两种mnemonics. 例如,JA(如果以上跳动)指令和JNBE(如果不低于或等于跳动)指令是操作码 77H的交替模式.

Jcc指令不支持远跳(跳转到其他代码段). 当有条件跳跃的目标处于不同的段位时,使用与Jcc指令测试的条件相反的条件,然后以无条件的远跳(JMP指令)进入另一个段位. 例如,以下有条件的远跳是非法的:

JZ FARLABEL;

要完成这一远处的跳跃,请使用以下两个指令: 1. (二) JNZ BEYOND; (二) JMP FARLABEL; BEYOND : (英语).

JRCXZ,JECXZ,和JCXZ指令与其他Jcc指令不同,因为它们不检查状态标志. 相反,他们检查RCX,ECX或CX为0. 选中的寄存器由地址大小属性决定 。 这些指令在以有条件的循环指令(如LOOPNE)终止的循环开头使用时有用. 它们可用于防止一个指令序列在RCX,ECX或CX为0时进入循环. 这将导致循环执行264,232或64K倍(而不是零倍).

所有有条件的跳转都转换为一两条缓存行的代码获取,无论跳转地址或缓存性如何.

在64位模式下,操作数大小固定在64位. JMP Short是RIP = RIP + 8位偏移符号扩展为64位. JMP Near is RIP = RIP + 32位偏移符号扩展为64位.

## 行动

```text
IF condition
    THEN
          tempEIP := EIP + SignExtend(DEST);
          IF OperandSize = 16
                THEN tempEIP := tempEIP AND 0000FFFFH;
          FI;
    IF tempEIP is not within code segment limit
          THEN #GP(0);
          ELSE EIP := tempEIP
    FI;

FI;
```
