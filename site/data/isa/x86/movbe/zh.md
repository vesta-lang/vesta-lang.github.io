## 说明

在从第二个 操作数 (源操作数) 复制的数据上执行字节互换操作,并将结果存储在第一个 操作数 (目标操作数) 上. 源操作数可以是通用寄存器,也可以是内存位置;目的地登记册可以是通用寄存器,也可以是内存位置;然而,两个操作数都不能成为登记册,只有一个操作数可以是内存位置. 操作数两个字必须大小相同,可以是单词,双字或四字.

MOVBE 指令用于将字节从内存读取或写入到内存;从而支持将小endian值转换为大endian格式,反之亦然.

在64位模式下,指令的默认操作大小为32位. 使用REX.R前缀可以访问额外的登记册(R8-R15). 使用REX.W前缀将操作提升到64位. 参见本节开头的汇总图,用于编码数据和限制.

## 行动

```text
TEMP := SRC

IF ( OperandSize = 16)

    THEN
          DEST[7:0] := TEMP[15:8];
          DEST[15:8] := TEMP[7:0];

   ELES IF ( OperandSize = 32)

          DEST[7:0] := TEMP[31:24];
          DEST[15:8] := TEMP[23:16];
          DEST[23:16] := TEMP[15:8];
          DEST[31:23] := TEMP[7:0];

   ELSE IF ( OperandSize = 64)

          DEST[7:0] := TEMP[63:56];
          DEST[15:8] := TEMP[55:48];


          DEST[23:16] := TEMP[47:40];
          DEST[31:24] := TEMP[39:32];
          DEST[39:32] := TEMP[31:24];
          DEST[47:40] := TEMP[23:16];
          DEST[55:48] := TEMP[15:8];
          DEST[63:56] := TEMP[7:0];

FI;
```

## 受影响的旗帜

None.
