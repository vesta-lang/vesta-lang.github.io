---
summary: 从 MMX 技术移动到 XMM 登记册
---

## 说明

将四字从 源操作数(第二个操作数)移动到 目标操作数(第一个操作数)的低四字. 源操作数是一个MMX技术登记册,目标操作数是一个XMM登记册.

本指令导致从x87 FPU到MMX技术操作的过渡(即将x87 FPU顶端-of-栈指针设置为0,将x87 FPU标记词设置为所有 0s [有效]). 如果执行此指令时有一个 x87 FPU 浮点 例外待决,则在 MOVQ2DQ 指令执行前处理该例外.

在64位模式中,使用REX.R前缀允许此指令访问额外的注册(XMM8-XMM15).

## 行动

```text
DEST[63:0] := SRC[63:0];
DEST[127:64] := 00000000000000000H;
```

## Intel C/C++ 内在编译器

```c
MOVQ2DQ__128i _mm_movpi64_epi64 ( __m64 a);
```

## SIMD 浮点 例外

None.
