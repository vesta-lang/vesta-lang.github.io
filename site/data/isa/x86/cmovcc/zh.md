## 说明

如果EFLAGS登记册(CF、OF、PF、SF和ZF)中的状态标志处于指定状态(或条件),则每个CMOVcc指令都执行移动操作。 每个指令都附有一个条件代码(cc),以说明所测试的条件。 如果条件不能满足,则不进行移动,继续按照CMOVcc指令执行指令。

具体来说,CMOVcc从它的源操作数无条件将数据加载到一个临时登记册中(无论条件代码和EFLAGS登记册中的状态标志). 如果与指令(cc)相关的条件代码得到满足,则临时寄存器中的数据随后被复制到指令的目标操作数中.

这些指令可以将16位,32位或64位值从内存移动到通用寄存器或从一个通用寄存器移动到另一个. 不支持8位寄存器操作数的有条件移动.

上表描述栏列出每个CMOVcc mnemonic的条件. 比较有符号整数时使用"小"和"大"两个词,比较无符号整数时使用"以上"和"以下"两个词.

由于状态标志的特定状态有时可以有两种解释,因此对一些操作码定义了两种mnemonics. 例如,CMOVA(如果以上为有条件移动)指令和CMOVNBE(如果不低于或相等为有条件移动)指令是操作码 0F 47H的交替模式.

CMOVcc指令是在P6家庭处理器中引入的;然而,这些指令可能不会得到所有IA-32处理器的支持. 软件可以通过使用CPUID指令(参见本章中的"CPUID--CPU识别")检查处理器的特性信息来判断CMOVcc指令是否得到支持.

在64位模式下,指令的默认操作大小为32位. 使用REX.R前缀可以访问额外的登记册(R8-R15). 使用REX.W前缀将操作提升到64位. 参见本节开头的汇总图,用于编码数据和限制.

## 行动

```text
temp := SRC

IF condition TRUE
    THEN DEST := temp;

ELSE IF (OperandSize = 32 and IA-32e mode active)
    THEN DEST[63:32] := 0;

FI;
```
