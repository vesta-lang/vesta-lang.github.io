summary: 在条件上设置字节
---

## 说明

根据状态标志(CF,SF,OF,ZF,和PF)在EFLAGS登记册中的设置,将目标操作数设置为0或1. 目标操作数指代一个字节寄存器或一个字节内存. 条件代码后缀(cc)表示正在测试的条件.

术语"以上"和"以下"与CF旗相关,指两个无符号整数值之间的关系. "大"和"小"这两个术语与SF和OF旗有关,并指两个签名的整数值之间的关系.

许多SETcc指令操作码都有交替的mnemonics. 例如,SETG(如果较大则设置位元)和SETNLE(如果不小或相等则设置位元)具有相同的操作码,且测试条件相同: ZF 等于 0,SF 等于 OF. 提供了这些备选的演示词,以使代码更加易懂。 附录B"EFLAGS条件代码",在Intel(R)64和IA-32架构软件开发者手册第1卷中显示了各种测试条件的交替模式.

一些语言代表一个逻辑的,作为所有位集的整数. 这种表示可以通过选择SETcc指令的逻辑相反条件来获得,然后降低结果. 例如,为了测试溢出,使用SETNO指令,然后降低结果.

ModR/M字节的reg字段不用于SETCC指令,那些操作码比特被处理器忽略.

在IA-64模式中,操作数大小固定在8位. 使用 REX 前缀可以实现对额外字节注册符的统一地址. 否则,此指令的操作与遗留模式和兼容模式相同.

## 行动

```text
IF condition
    THEN DEST := 1;
    ELSE DEST := 0;

FI;
```

## 受影响的旗帜

None.
