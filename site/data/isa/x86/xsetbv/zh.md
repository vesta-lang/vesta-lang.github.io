## 说明

将登记EDX:EAX的内容写入控制寄存器(XCR)中指定的64位扩展的控制寄存器(ECX). (关于支持Intel 64架构的处理器,RCX的高阶32位被忽略. ) EDX寄存器的内容被复制到选定的XCR的高阶32位,EAX寄存器的内容被复制到XCR的低阶32位. (关于支持Intel 64架构的处理器,RAX和RDX的每个高序32比特被忽略. ) XCR中未定义或保留的比特应设定为先前读取的值.

此指令必须在特权级别0或实地址模式执行;否则,生成一般保护例外#GP(0). 在 ECX 中指定一个保留或未执行的 XCR 也会引起一般的保护例外. 如果软件试图在 XCR 中写入保留位元,处理器也会生成一般保护例外.

目前,仅支持XCR0. 因此,ECX的所有其他值都是保留下来的,并将产生#GP(0). 注意, XCR0 的比特 0 (对应 x87 状态) 必须设置为 1; 如果试图清除此比特, 指令将会导致 #GP(0) 。 此外,如果尝试在清除XCR0[1](SSE状态)的同时设置XCR0[2](AVX状态);需要设置两个比特来使用AVX指令,则该指令会产生#GP(0); 第13.3节,"赋予XSAVE特性集和XSAVE-Enabled Features",Intel(R)64和IA-32 架构软件开发者手册,第一卷.

## 行动

```text
XCR[ECX] := EDX:EAX;
```

## 受影响的旗帜

None.

## Intel C/C++ 内在编译器

```c
XSETBV void _xsetbv( unsigned int, unsigned __int64);
```
