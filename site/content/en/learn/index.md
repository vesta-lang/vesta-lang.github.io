# Learn Vesta

This is a path, not a reference. The chapters are meant to be read in order:
each one assumes the previous, and each ends with code you can run.

If what you need is the answer to one specific question, that lives in the
[documentation](/docs/), which assumes nothing and is exhaustive.

## Where to start

If you have never built Vesta, start by [installing it](/download/) and carry on
with [hello world](/learn/hello-world/). It takes ten minutes.

If you already have it running and you come from C, C++ or Rust, [the three
modes](/learn/three-modes/) covers the first thing that surprises people: that
the same source runs on a virtual machine, compiles while it runs, or becomes a
native binary with no runtime at all.

## The whole path

The sidebar holds the full index. It is written from less to more: syntax first,
then memory and abstraction, and the parts that make Vesta different (its
compile-time, its standard library written in the language itself, and its
runtime) arrive once you can already read the code.

Chapters shown without a link are not written yet. They are listed anyway so you
can see the whole path.
